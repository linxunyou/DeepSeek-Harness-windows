==========================================
  DeepSeek Harness 桌面版 - 使用说明
==========================================

【环境要求】（首次使用需安装）
  1. Node.js v22+    -> https://nodejs.org/
  2. Git             -> https://git-scm.com/
  3. pnpm            -> 打开命令行输入: npm install -g pnpm

【启动应用】
  双击 start.bat

  首次启动会自动下载、安装、编译 DeepSeek Harness（约10-30分钟），
  请耐心等待。后续启动会直接打开窗口。

【打包为独立 .exe】
  双击 build.bat
  生成文件在 dist 文件夹: DeepSeek-Harness.exe

【窗口行为】
  点击关闭按钮 (X) -> 窗口隐藏到系统托盘，程序继续运行
  双击托盘图标     -> 重新显示窗口
  托盘右键 -> 退出 -> 完全关闭程序

【常用操作】（右键系统托盘图标）
  显示窗口       - 重新显示隐藏的窗口
  重启服务       - 重启后端
  重新部署       - 清除环境后重新安装
  检查更新       - 手动检查 DeepSeek Harness 新版本

【自动更新】
  - DeepSeek Harness 版本：启动时自动检查，每4小时检查一次
  - 应用程序自身版本：启动时自动检查 GitHub 最新版本
    如有更新会弹窗提示，确认后可自动下载并替换

【常见问题】
  Q: 窗口空白？
  A: 右键托盘 -> 重启服务，等待几秒

  Q: 部署卡住不动？
  A: 首次编译耗时较长，请耐心等待进度条更新

  Q: 想彻底重装？
  A: 删除 dsh-env 文件夹后重新启动

  Q: start.bat 闪退？
  A: 右键 start.bat -> 编辑，在最前面加 pause，
     然后双击运行查看错误信息
